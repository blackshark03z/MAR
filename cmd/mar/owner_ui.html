Kết nối AI

ChatGPT dùng OpenAI Secure MCP Tunnel làm đường kết nối chính. Thiết lập Tunnel ID một lần, sau đó MAR giữ nguyên identity và tự kết nối lại sau restart. Claude dùng đường riêng, độc lập. Server URL / Quick Tunnel chỉ là fallback tạm thời để debug và hostname có thể thay đổi.

  1. Tạo hoặc chọn Secure MCP Tunnel trong OpenAI.
  2. Dán Tunnel ID vào MAR và chọn Lưu & kết nối.
  3. Sau đó chỉ cần mở MAR; tunnel cũ sẽ tự resume khi đủ credential.
